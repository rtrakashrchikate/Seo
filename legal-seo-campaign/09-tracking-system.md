## Section 1: Free Tools Setup

### Tool 1: Google Search Console (GSC)

**Setup:**
1. Go to: https://search.google.com/search-console/
2. Add property: `https://advocateakashchikate.com/` (URL-prefix method)
3. Verify ownership via HTML tag in `<head>` or DNS record
4. Submit sitemap: `https://advocateakashchikate.com/sitemap.xml`
5. Submit sitemap for images: `https://advocateakashchikate.com/image-sitemap.xml` (if using WordPress SEO plugin)

**Weekly checks:**
- Performance > Search results: Review top queries by impressions and clicks
- Indexing > Pages: Check for "Not indexed" pages and fix errors
- Experience > Core Web Vitals: Check LCP, CLS, INP status
- Enhancements: FAQs, breadcrumbs, sitelinks search box — confirm no errors

### Tool 2: Google Analytics 4 (GA4)

**Setup:**
1. Create property at: https://analytics.google.com/
2. Add GA4 measurement ID to website
3. Create conversion events:
   - `contact_form_submit` (form submissions on Contact page)
   - `phone_click` (clicks on tel: links)
   - `whatsapp_click` (clicks on WhatsApp button)
   - `pdf_download` (checklist downloads)
4. Create audience: "Contacted (30 days)" — users who completed any conversion in last 30 days

**Monthly review:**
- Users by source: Organic search / Direct / Social / Referral
- Top landing pages: Which pages drive organic traffic
- Conversion events: How many contact form submissions per month
- User location: Confirm Pune / Maharashtra / India dominant — no spam traffic

### Tool 3: Google Business Profile Insights

**Weekly checks (via GBP dashboard):**
- Search type: Direct (name search) vs. Discovery (category search) vs. Branded
- Queries used to find the profile — track which search terms appear
- Customer actions: Website visits, direction requests, phone calls from GBP
- Photo views vs. competitor average

| Direction requests | [record at Day 1] | +15% | +30% | +50% |

### Tool 4: Ubersuggest (Free Tier)

**Setup:**
1. Go to: https://neilpatel.com/ubersuggest/
2. Add project for `advocateakashchikate.com`

### Tool 5: Ahrefs Webmaster Tools (Free)

**Setup:**
1. Go to: https://ahrefs.com/webmaster-tools
2. Verify site ownership
3. Check: Site Explorer > Backlinks (new backlinks appearing each week)
4. Check: Site Audit > Technical issues

**Weekly check:**
- New backlinks: Record in link acquisition tracker (Section 5)
- Lost backlinks: Investigate and recover if valuable
- Organic keywords: New keywords entering top 100

### Tool 6: PageSpeed Insights

- URL: https://pagespeed.web.dev/
- Test homepage weekly during first month, then monthly
- Record: Mobile LCP, CLS, INP, FCP, TTFB scores
- Target: All Core Web Vitals in "Good" (green) range

### Tool 7: Rich Results Test

- URL: https://search.google.com/test/rich-results
- Test after any schema change
- Test all 5 key pages monthly: homepage, anticipatory bail, FIR quashing, NDPS, contact
- Confirm: FAQs, breadcrumbs, sitelinks showing as valid

As ChatGPT, Perplexity, Gemini, and Grok increasingly answer legal queries directly, being cited by these engines drives:
- Branded searches (people searching "Advocate Akash Chikate" after seeing AI mention)
- Direct visits from AI-directed users
- Authority reinforcement for Google ranking

### Weekly AI Citation Check Spreadsheet

**Columns:**

## Section 5: Link Acquisition Tracking Spreadsheet

**Columns for the spreadsheet:**

```
Date | Source Domain | URL of Link | Anchor Text | DA/DR | Link Type | How Acquired | Status | Notes
```

**Status values:**
- Outreached — awaiting response
- Confirmed — link live
- Rejected
- No response

**Monthly targets:**
- Month 1: 5–8 new backlinks (citation submissions + 1–2 editorial)
- Month 2: 8–12 new backlinks (outreach conversions + content links)
- Month 3: 5–8 new backlinks (guest posts, resource pages, PR links)

**Minimum DA/DR threshold for tracking:**
- Track all links with DA 20+ or known legal relevance
- Citation directories (DA 30–50) count as acquired links

## Section 6: GSC Monitoring Checklist

### Weekly GSC Review (15 minutes)

- [ ] Any new crawl errors or indexing issues in "Indexing > Pages"?
- [ ] Core Web Vitals: Any URLs entered "Poor" status?
- [ ] Performance: Any dramatic impressions drop (>20% week-on-week)?
- [ ] Manual actions: Confirmed "No issues detected" in Security & Manual Actions
- [ ] New pages indexed: Are all pages published in the last 7 days indexed?

### Monthly GSC Review (30 minutes)

- [ ] Download top 25 queries by impressions; compare to last month
- [ ] Check CTR for top queries: any with impressions but <2% CTR? (Title/meta improvement needed)
- [ ] Check top landing pages: which pages gained organic traffic?
- [ ] Links report: Any new referring domains? Check in Ahrefs for quality
- [ ] International targeting: Confirm `hreflang` for Marathi pages showing correctly
- [ ] Sitelinks: Are sitelinks appearing for branded search? If odd sitelinks, demote via GSC

## Section 10: Success Metric Definitions

| Metric | Definition | Measurement Method |
|--------|------------|--------------------|
| Organic sessions | Visits from Google/Bing where source = organic | GA4 > Acquisition > Source/Medium |
| Impressions | Times site appeared in Google search results | GSC > Performance > Total Impressions |
| Clicks | Times a searcher clicked to the site from Google | GSC > Performance > Total Clicks |
| Average position | Mean rank of all impressions | GSC > Performance > Average Position |
| GBP views | Times GBP profile appeared in search or Maps | GBP Insights > Total Views |
| Backlink | Any inbound link from an external domain | Ahrefs Webmaster Tools > Backlinks |
| New referring domain | A domain linking for the first time | Ahrefs > New Referring Domains |
| AI citation | Site URL or entity name appearing in AI answer | Manual Monday check across 4 platforms |
| Conversion | Contact form submission or phone click | GA4 conversion events |
| Featured snippet | Position 0 answer box in Google SERP | GSC Performance filter + manual check |
