## Section 7: Core Web Vitals Targets

| Metric | Target | Current Action |
|--------|--------|----------------|
| LCP (Largest Contentful Paint) | < 2.5 seconds | Compress hero image; use WebP format; preload LCP image |
| CLS (Cumulative Layout Shift) | < 0.1 | Set explicit width/height on all images; avoid late-loading ads |
| INP (Interaction to Next Paint) | < 200 ms | Minimise JavaScript; defer non-critical scripts |
| FCP (First Contentful Paint) | < 1.8 seconds | Inline critical CSS; defer non-critical CSS |
| TTFB (Time to First Byte) | < 600 ms | Use quality Indian hosting (Cloudflare CDN strongly recommended) |

### Core Web Vitals Implementation Steps
1. Install Cloudflare (free tier) for CDN and caching
2. Convert all images to WebP format (use Squoosh.app)
3. Add `loading="lazy"` to all below-fold images
4. Add `fetchpriority="high"` to the hero/LCP image
5. Use async/defer on all non-critical JavaScript
6. Enable GZIP or Brotli compression on server
7. Use WordPress caching plugin (WP Rocket or W3 Total Cache)
8. Test weekly at: https://pagespeed.web.dev/
